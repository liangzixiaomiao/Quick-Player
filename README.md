# 倍速压缩工坊

把长视频按倍速压进指定时长的小工具，纯前端实现，单个页面即用：**不上传视频、不需要安装 ffmpeg、不需要后端**。

## 使用

直接用浏览器打开 `index.html` 即可（也可以放到任意静态托管，如 GitHub Pages）。

1. 拖入或选择视频文件
2. 在时间轴上拖动两侧手柄，裁出要保留的片段
3. 填写目标时长（秒），或点 1/3/5/10 分钟预设，倍速会自动算出
4. 勾选「预览快放」按真实倍速试看，或点「预览片段」只听选中区间
5. 点「开始导出」，完成后可在线回放并下载 MP4 / WebM

快捷键：`空格` 播放/暂停，`←` `→` 前后 5 秒，`Shift + ←/→` 前后 1 秒。

## 实现方式

视频在浏览器本地解码，按选定倍速播放并逐帧绘制到 canvas，再用 `canvas.captureStream()` + `MediaRecorder` 录制成文件。

- `index.html` 页面结构
- `styles.css` 样式
- `app.js` 全部逻辑（时间轴裁剪、倍速计算、音频链路、导出）

## 已知限制

导出是**实时录制**，耗时约等于输出时长，期间需要保持标签页在前台。

成片时长由「本机解码 + 编码能否跟上倍速」决定，因此可能与目标时长有偏差：结果区会显示实际输出时长，偏差较大时提示改用 WebM 或降低分辨率。实测在同一台机器上，WebM(VP8/VP9) 通常比 MP4(H.264) 更容易跑满倍速。

其他说明：

- 浏览器需支持 `MediaRecorder` 与 `canvas.captureStream`（Chrome / Edge 均可）
- 「音调不变」会让音频走变调补偿，倍速较高时会拖慢播放，追求时长准确可关闭
- 不做逐帧离线编码，所以无法保证精确到毫秒的定长输出

## 隐私

视频只在本地浏览器内处理，页面不发送任何网络请求，不会上传文件。仓库中也不包含任何用户数据。

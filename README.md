# 倍速压缩工坊

把长视频按倍速压进指定时长的小工具，纯前端实现，单个页面即用：**不上传视频、不需要安装 ffmpeg、不需要后端**。

## 使用

直接用浏览器打开 `index.html` 即可（也可以放到任意静态托管，如 GitHub Pages）。

1. 拖入或选择视频文件
2. 在时间轴上拖动两侧手柄，裁出要保留的片段
3. 填写目标时长（秒），或点 1/3/5/10 分钟预设，倍速会自动算出
4. 勾选「预览快放」按真实倍速试看，或点「预览片段」只听选中区间
5. 点「开始导出」，完成后可在线回放并下载 MP4 / WebM

快捷键：`空格` 播放/暂停，`←` `→` 前后 5 秒，`Shift + ←/→` 前后 1 秒。

## 实现方式

导出有两条路径，默认走「离线编码」：

**离线编码（MP4，Chrome / Edge 105+）**
`mp4box.js` 解封装 → `VideoDecoder` 解码 → 按目标时间轴抽帧并缩放到 canvas → `VideoEncoder` 重新编码 → `mp4-muxer` 封装。音频同样解封装后重采样、用 `AudioEncoder` 编成 AAC。整个过程不依赖墙钟，**耗时只和源视频长度、本机编码速度有关**，与成片时长无关，输出时长精确到帧。

**实时录制（WebM，或其他浏览器 / 编码不支持时自动回退）**
视频按倍速播放，`canvas.captureStream()` + `MediaRecorder` 录制，耗时约等于成片时长。

文件：

- `index.html` 页面结构
- `styles.css` 样式
- `app.js` 界面、时间轴裁剪、倍速计算、导出调度、实时录制
- `offline-export.js` 离线编码（解复用 → 解码 → 抽帧 → 编码 → 封装）
- `vendor/` 第三方库（mp4box.js 解封装、mp4-muxer 封装），均为本地文件，不联网

## 已知限制

- 离线编码只接受 **H.264 + AAC 的 MP4**；其他编码/容器会自动回退到实时录制
- 离线编码的音频随速度一起快放，**音调会升高**（不做变调补偿）；勾选「音调不变」只影响实时录制路径
- 实时录制路径的成片时长受「本机解码 + 编码能否跟上倍速」影响，结果区会显示实际输出时长；追求速度请用 MP4
- 浏览器需支持 `MediaRecorder`、`canvas.captureStream`（WebM）与 WebCodecs（离线 MP4）

## 隐私

视频只在本地浏览器内处理，页面不发送任何网络请求，不会上传文件。仓库中也不包含任何用户数据。
